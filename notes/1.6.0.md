New:

* Support latest install4j v.13 ([Issue #21][issue-21])

Changes:

* Requires sbt 1.9 or newer, for older sbt 1.x use version 1.5.0
* Published through the Sonatype Central Portal, in Maven-compatible plugin layout

Bug fix:

* `install4jCompilerVariables` passed literal quotes to `install4jc`, corrupting the first variable name and the last
  value ([Issue #20][issue-20])
* setting `install4jCopyDependedJarsEnabled` is ignored, jars are always copied ([Issue #23][issue-23])
* `install4jDependedJarsDir` is never used, it is ignored ([Issue #24][issue-24])
* `copyDependedJars` never cleans `crossTarget/lib`, stale jars from old dependency versions get bundled ([Issue #25][issue-25])
* On an unrecognized OS (e.g. FreeBSD) project fails to load even when `INSTALL4JC_FILE` is set ([Issue #26][issue-26])
