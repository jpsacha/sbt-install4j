
New:
* Support latest install4j v.13 #21 ([Issue #21][issue-21])

Bug fix:
* `install4jCompilerVariables` passed literal quotes to `install4jc`, corrupting the first variable name and the last value ([Issue #20][issue-20])
* setting `install4jCopyDependedJarsEnabled` is ignored, jars are always copied #23
* `install4jDependedJarsDir` is never used, it is ignored #24
* `copyDependedJars` never cleans `crossTarget/lib`, stale jars from old dependency versions get bundled #25
* On an unrecognized OS (e.g. FreeBSD) project fails to load even when `INSTALL4JC_FILE` is set #26

[issue-20]: https://github.com/jpsacha/sbt-install4j/issues/20
[issue-21]: https://github.com/jpsacha/sbt-install4j/issues/21
