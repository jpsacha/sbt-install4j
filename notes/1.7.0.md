New:

* Support sbt 2 ([Issue #22][issue-22]). The plugin is cross-built for sbt 1 (1.9 or newer) and sbt 2 (requires JDK 17
  or newer)

Changes:

* `install4j` compiler output is sent to the sbt logger instead of printed directly to the console,
  error output is logged as warnings
* `install4j` fails with a clear message when the install4j compiler exits with a non-zero exit code

[issue-22]: https://github.com/jpsacha/sbt-install4j/issues/22
